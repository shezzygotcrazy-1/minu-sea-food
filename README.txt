Minu Seafoods website
=====================
Open index.html in any browser to preview. It is a single self-contained page.

To put it online: upload index.html to any web host (cPanel public_html, Netlify, Vercel, GitHub Pages, etc.).

To edit:
- Replace the highlighted placeholders in the Contact section (phone, email, address, hours).
- Replace the logo (the small SVG inside the <header>).
- Edit the product list in the "items" array near the bottom of the file.
- To use photos instead of the drawings, put image files next to index.html and change the art() output
  in the script to an <img src="your-photo.jpg" alt="..."> tag.

Note: the enquiry form builds a message to copy into WhatsApp or email. To receive form submissions
directly, connect a form service (Formspree, Web3Forms, etc.) or a backend.
